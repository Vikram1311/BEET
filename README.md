# BEET

BEET ek multi-category marketplace hai jahan users 70+ ready templates se posters aur marketing videos bana, upload aur share kar sakte hain; saath hi jobs post aur search kar sakte hain.

## Core Modules

- Category-wise 70+ template library
- Poster and marketing video editor
- Upload and social sharing
- Job posting and job search
- Employer and job seeker profiles
- Applications, saved jobs, and shortlisting

## Technology

- Next.js App Router
- React
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```
